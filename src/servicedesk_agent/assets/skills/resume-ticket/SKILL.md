# Resume Ticket

1. Read the saved handoff when `read_handoff` is available.
2. Preserve the saved user constraints and outstanding actions.
3. Read the current ticket. Check its current owner, status, dependencies and workflow.
4. Consult the current policy version when the remaining action depends on policy.
5. Continue authorized unresolved work and verify its actual tool receipt.
6. Save the remaining work. Historical observations remain available as historical evidence.
